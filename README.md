## 🎨 设计标准（所有新页面必须遵守，防止走样）

- **用户永远有输入的权力（2026-10-15 产品负责人定）**：AI 生成的任何内容（稿子、标题、回复、方案），用户都能① 直接点着改；② 随时"说一句"让 AI 改（"开头温和点""加一句机构名字"）。页面不允许只给"接受/重来"两个按钮，必须留出用户自己的手和嘴。
- **决策主权（2026-10-15 产品负责人重申）**：写什么、发什么、回什么，**永远由用户拍板**。AI 的职责只有两条：在用户拍板前给足候选；在用户拍板后执行到底。创作页必须标明"这条主题是你选的 / 你出的"，并永远提供[换主题][自己出题]的入口；任何页面都不得出现"AI 自己把事定了"的样子。
- **风格**：Marvis 极简风 + 苹果风、柔和灰阶（不用高对比黑白；产品负责人 2026-10-16 钦定"Marvis 的极简风格就是我的理想型"，全站数值以《Marvis设计语言-提取报告》为准）
- **字体**：系统字体栈 + Noto Sans SC（思源黑体）
- **图标**：Tabler Icons（本地字体 `设计原型/assets/tabler-icons.woff2`），不用 emoji 当图标
- **主色**：单一强调蓝 `#0080ff`（Marvis 值；深色模式 `#0a84ff`），不引入第二强调色
- **底色与灰阶**（浅色，Marvis 体系）：页面 `#f7f7f7` / 卡片纯白 `#ffffff` / 悬停 `rgba(15,15,15,.06)`；文字=黑透明度阶梯 主 `rgba(0,0,0,.75)` / 次 `.55` / 弱 `.38`；深色模式对应 `#1c1c1e` / `#2c2c2e` / `#e8e8ed` / `#a8a8af` / `#82828a`
- **阴影三档**（Marvis 配方，全站只允许这三档）：卡片 `0 4px 10px rgba(0,0,0,.03)`；浮层 `0 8px 16px rgba(0,0,0,.08)` 或发丝+投影 `0 0 1px rgba(0,0,0,.3), 0 4px 14px rgba(0,0,0,.1)`；模态=多层配方（token `--shadow-modal`）。禁止重阴影
- **字号 / 字重**：字号只用 12 / 13 / 14 / 16（大标题另算）；字重只用 400 / 500 / 600
- **圆角档位**：8 / 12 / 20 / 28（微件 4），保留超椭圆；按钮胶囊（全圆角）
- **滚动条**：4px 极细（Marvis 值），灰色滑珠
- **侧栏语法**（2026-10-16 定，防走样）：分组标签=素面小字（悬停只加深文字与图标，不许出现灰块）；条目=悬停浅灰 `rgba(15,15,15,.06)`、选中稍深 `rgba(15,15,15,.10)`；**选中一律不加粗**（选中靠底色表达，不许"底色+加粗"叠着来）
- **结构（2026-10-16 定，一劳永逸的地基）**：全站样式只有一个来源 **`设计原型/assets/jco-ui.css`（J.Co UI Kit）**；12 个页面只保留"本页独有"样式；改公共样式=改 UI Kit 一处，全站生效。**新页面必须从 UI Kit 拿零件，不允许再出现"第二个版本"。** 零件橱窗：`设计原型/J.Co设计系统.html`（色彩/文字/圆角/阴影/侧栏零件/菜单浮层/图标全集）。
- **两道门（交付前必过，2026-10-16 定）**：① 结构检查 `preflight` 必须 0 违规；② 视觉守门员逐元素比对（工程 `work\round7\verify-computed.cjs`）：改完样式后自动对比前后每个元素的 36 项样式，有差异必须解释清楚才放行。
- **双模式**：跟随系统深浅色，两套都必须在交付前自测
- **动效**：轻量（悬停微抬、缓入），必须支持 `prefers-reduced-motion`
- **交付标准**：① design-taste 技能包的 preflight 脚本 0 违规；② 模拟点击测试全绿、零报错；③ 截图自检后才可交产品负责人；④ 设计数值有据可依（以《Marvis设计语言-提取报告》为准，不再随手改）
