# 全站验收指南 · 一晚上跑了什么、你醒来怎么过一遍（2026-10-17）

> 桌面 J.Co 已是 **0.4.16**（双击打开即最新版）。本指南按"你要做什么 → 应该看到什么"写，
> 15 分钟可过完全部核心动线。哪里不对，直接说一句就行。

## 先看三件最值钱的（各 1 分钟）

### 1. 说一句话，AI 自己干活（本次最大变化）

- 做法：打开 J.Co → 首页底部输入「帮我做一条暑期招生的口播视频」→ 回车
- 应该看到：自动跳到总管的**任务视图**，AI 边干边有提示（"AI 正在干活…"）；
  跑完变"跑完了"，左侧「任务」区留一条带 ✓ 的记录，点开能看全过程；跑完弹系统通知
- 意义：这就是"AI 像人一样先想后干"的入口——不是脚本，每一步都会应变

### 2. 总管会话列表（修好了）

- 做法：看总管页左侧「对话」区
- 应该看到：**你自己的真实会话列表**（0.4.7–0.4.11 期间这里曾只显示示例、点不动——已修）
- 还能：每条点 ⋯ 可重命名/删除；「新会话」按钮在搜索框正下方

### 3. 任务分区回看

- 做法：左侧「任务」区点任何一条（✓ 或 ✗）
- 应该看到：完整的"你说了什么 + AI 干了什么"；正在跑的任务直接显示"在跑"
