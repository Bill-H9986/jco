# 前端页面 × 调研报告 对照表

> 规矩：每个页面交付时，功能必须能对上《AI自媒体工作流与开源项目调研报告》里的调研结论；将来"接真本事"时，按"靠什么实现"一列去选型（多为报告里调研过的开源项目）。
> 建档 2026-10-15。

## 1. 选题（定位与选题）

| 页面功能 | 出自调研哪一条 | 将来靠什么实现 |
|---|---|---|
| 我的对标账号（AI 每天盯同行更新） | 报告：自媒体运营工具「对标账号监控」；掘金实践《一键采集对标账号作品》 | 浏览器自动化采集（MediaCrawler / TikHub 类数据源） |
