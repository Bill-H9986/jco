## 六、附则 · 引入新机制的要求

1. **可溯源**：任何新机制/新做法进入本项目，必须指明源头（官网 / 标准 / 论文 / 仓库），并写入相应文档的"理论基础/出处"表；
2. **先调研**：找不到现成源头的，先做《先例调研笔记》；
3. **确实无先例的自研**：明确标注"自研"，说明为什么业界方案不适用——**默认从怀疑自己开始**；
4. **"能抄就抄"**：优先适配现成方案，自研只留给真正独特的部分（如产品负责人定义的产品哲学）。
