> 事实来源：应用启动后的浏览器计算样式，不是静态 CSS 搜索。

## 二、统一规格

| 元素类型 | 唯一规格 |
|---|---|
| 标准文本按钮 | 36px 高、10px 圆角、左右 14px、13px 字 |
| 紧凑按钮/参数/分段 | 30px 高、8px 圆角、左右 10px、12px 字 |
| 圆形图标按钮 | 40×40px、正圆 |
| 方形图标按钮 | 32×32px、8px 圆角 |
| 开关 | 44×26px、圆钮 22px、无页面级阴影 |
| 卡片 | 16px 圆角 |
| 状态徽章 | 24px 高、胶囊形、12px 字 |
| 标准输入 | 36px 高、10px 圆角、13px 字 |
| 页头 | sticky 顶部，标题统一 `x=32, y=36` |

几何轮廓：

- 正圆、胶囊、开关、圆形头像、进度条：`corner-shape: round`，浏览器计算值为 `superellipse(1)`；
- 文本按钮、紧凑按钮、方形图标、输入框、卡片、弹层：`corner-shape: superellipse(1.5)`；
- 页面内联样式不得定义 `corner-shape`。

## 四、修改前后

| 修改前 | 修改后 | 原因 |
|---|---|---|
| `.go-btn` 同时存在 40px 胶囊和 40px 矩形 | 统一 36px 高、10px 圆角矩形 | 同一主要操作只保留一种形状 |
| `.btn-ghost` 在设置页被局部改成 34px 胶囊 | 全部 36px 标准矩形 | 同功能按钮必须同规格 |
| `.ghost-btn` 34px 胶囊、`.tbtn` 34px 矩形 | 全部 36px 标准矩形 | 消除同一功能两套外观 |
| 圆图标从 28/34/36/38/40/52px 混用 | 全部 40×40px 正圆 | 圆图标只保留一种尺寸 |
| 方图标从 28/30/34px 混用 | 全部 32×32px、8px 圆角 | 方图标只保留一种尺寸 |
| 开关有页面级 inset 阴影差异 | 44×26、无外层阴影、圆钮一致 | 开关只保留一种视觉 |
| 14 个页面各自维护 `corner-shape: round` 名单，同类开关在不同页面变成椭圆或圆角矩形 | 全部页面级轮廓名单删除，只保留共享几何契约 | 同类元素只允许一套实际轮廓 |
| 卡片圆角 12/20/22/28px 混用 | 统一 16px | 卡片只保留一套形状 |
| 输入高度 38/40px、圆角 12px | 统一 36px、10px 圆角 | 表单控件同一规格 |
| 徽章高度 20/21/24/25/26/30px 混用 | 统一 24px 胶囊 | 状态标签同一规格 |

## 五、防止再次分叉

1. `jco-ui.css` 末尾有操作控件和几何轮廓契约，页面局部样式不能改写尺寸、圆角、内边距、固定宽度或 `corner-shape`。
2. `check-ui-source.mjs` 扫描所有页面的 `<style>`，发现页面重复定义共享控件尺寸或 `corner-shape` 即失败。
3. `ui-inventory.mjs` 启动真实应用读取计算样式，覆盖 382 个圆角元素，避免“CSS 写了但被页面覆盖”。
4. `m16-ui-contract` 在 E2E 中再跑一次，并覆盖图片详情动态状态。
5. `qa-installed-ui.mjs` 对安装后的真实 exe 复验，不只看源码目录。
