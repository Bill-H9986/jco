> 给未来的自己/工程师：J.Co 的"地基"是怎么搭的、每个部件在哪、怎么往下长。

## 一句话架构

```
J.Co 桌面应用（Electron 44.7.0）
├─ 渲染进程：12 个原型页面（设计原型/，苹果风 UI）
│    └─ 检测到 window.jco（preload 注入）时启用"真模式"；浏览器直开＝演示模式
├─ preload.cjs：只暴露最小桥（ask / onDelta / status / probe / setModel）
└─ 主进程 main.js
     └─ kernel/bridge.mjs —— 内核桥（官方 @deepseek-ai/dsh-sdk-client 0.2.0-rc.2）
          └─ 子进程：DSH 内核（dsh --profile sdk，stdio JSON-RPC）
               └─ 模型路由（见下）
```

## 模型路由（三层，按设置页配置实时切换）

| 场景 | provider | 说明 |
|---|---|---|
| 未配置（兜底） | `deepseek-official` | 用本机 `~/.dsh` 里的 DeepSeek 账号凭据；开箱能聊 |
| 设置页选「Agnes 内置」+ 填 Key | `jco-custom`（动态 patch） | 指向 `https://api.agnes-ai.cn/v1`，用你充值的 Agnes 额度 |
| 设置页选「OpenAI 兼容接口」+ 填地址/Key/模型 | `jco-custom`（动态 patch） | 指向任意 OpenAI 兼容端点 |

机制：设置页「保存并使用」→ `kernel:set-model` IPC → 写 `app/kernel/model-config.json`
→ 生成 `app/kernel/dynamic-model.patch.yml`（llm-pi-ai 的 jco-custom provider）
→ 重建内核子进程 → 下一条消息按新路由走（保存后自动后台预热）。

## 关键实现细节（踩过的坑，改代码前必读）

1. **Electron 必须精确 44.7.0**：内核原生插件按指纹校验（43.0.0 / 44.0.0 / 44.7.0 / 45.0.0-alpha.6），44.7.2 会被拒绝。
2. **内核子进程要 `ELECTRON_RUN_AS_NODE=1`**：SDK 用 `process.execPath`（electron.exe）spawn 内核，不带这个变量会以 Electron 模式启动而失败。
3. **厂商网关不发实时增量**：Agnes / DeepSeek 都不走 `assistant/chunk`；正文与"真实出字时间戳"在 `assistant/message.data.stream` 里。桥里按时间戳压缩成 ≤2.5 秒的"回放帧"推给前端（逐字出现，不是一下蹦出）。
4. **错误必须如实上报**：回合失败时 `turn/end.reason.error.message` 拿到原始错误（如 Agnes 的 401），由 `friendlyError()` 翻译成一句人话返回给界面，绝不留白。
5. **会话 id 是进程内的**：同一个内核进程内复用 `sessionId` 可续上下文；换进程（改配置/重启应用）必须换新 id。
6. **配置含明文 Key**：存在 `app/kernel/model-config.json`（只在本机，不上云）。这是"不搬家"策略的一部分。

## 设置页各开关的实际含义

- 「测试连接」「搜索可用模型」：桌面应用内是**真 HTTP 探测**（`GET {地址}/models`，Bearer Key），如实报 401/超时；浏览器直开为演示数据。
- 「说话写稿」的三类里，只有它是内核当前消费的配置；画图/出片两类先落盘（localStorage），等做视频页接图像/视频工具时消费。
- 「Agnes 内置」= 端点与默认模型（agnes-2.5-flash）内置，用户只需贴一次 Key；其他类别切到 Agnes 时自动带出同一把 Key。

## 往下怎么长（下一步的接口点）

- **发布插件（第一个员工）**：内核工具面按角色挂载（参考 Bosom friend 的 `BF_AGENT_ROLE` 模式）；浏览器自动化走 Playwright MCP 或自研工具。
- **员工状态可视化**：内核的 `tool/call`、`tool/result` 通知已经在桥里可解析（暂未转发到界面），总管页"正在干嘛"实时展示直接接这两个事件。
- **跨启动续聊**：内核会话注册表限制下，换进程要换会话 id；持久化对话历史是后续工作。
- **画图/出片接内核**：`dsh-connect-agnes-token-plan` 的方案（`agnes_draw_image` / `agnes_video_generate` 工具）是现成参考，接入时按它抄。
