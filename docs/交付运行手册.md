### 自动更新

从 `0.6.0-beta.2` 起，应用内置自动更新：

- 启动 15 秒后检查，此后默认每 4 小时检查；
- 有新版本时后台下载并校验 SHA-512；
- 下载完成后，退出应用自动安装；
- 设置页可直接“检查更新 / 重启并更新”。

发布新版本：

```powershell
cd app
npm version <new-version> --no-git-tag-version
$env:JCO_UPDATE_FEED_URL = 'https://你的静态更新源/updates'
npm run release:package
```

把 `app\release\feed` 中的通道 yml、安装包和 blockmap 原样上传到该 HTTPS 地址。预发布版本会生成 `beta.yml` / `rc.yml`，稳定版生成 `latest.yml`。

本机联调：

```powershell
$env:JCO_UPDATE_ALLOW_INSECURE = '1'
npm run update:serve
```

当前 `0.6.0-beta.4` 安装版使用 `http://127.0.0.1:8787/updates` 完成了真机升级验证；生产包必须换成正式 HTTPS 地址，详见 `C:\Users\Jay\Documents\Codex\2026-10-17\zhu\outputs\需要你处理.md`。

## 8. 故障排查顺序

1. 先看 `git log -1`、`app/package.json` 和 `npm run gate`，区分源码、打包版和安装版；
2. 运行 `npm run check:all` 看迁移基线和视觉基准是否漂移；
3. UI/E2E 失败时先看对应证据文件和 `test-results`，不要用修改基线掩盖失败；
4. 内核问题检查模型配置和真实内核 smoke；浏览器问题检查会话文件和白名单；后期问题检查 ffmpeg 和成片目录；
5. 需要安装/卸载、真实平台登录、真实发布或删除数据时，停下并写 `C:\Users\Jay\Documents\Codex\2026-10-17\zhu\outputs\需要你处理.md`。
