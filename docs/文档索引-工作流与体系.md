## 三、冲突时以谁为准

```text
J.Co 软件开发工作流标准 v1.6
  > M11 设计冻结包 / 工作队列
  > 项目现状与风险清单 / 项目认知索引
  > 调研资料 / 历史笔记 / README / 一页纸
```

规则：

- **流程问题**只看 v1.6；不要拿某份调研笔记当流程。
- **当前事实**看项目现状与风险清单 + 可复现代码/测试。
- **产品内 AI 行为**看 AI 员工方法论；它不规定“我们怎么开发软件”。
- **新会话恢复**看会话交接协议；它不替代工作流标准。
- 调研资料可以保留多个版本，用于来源追踪；它们不是并行工作流。
