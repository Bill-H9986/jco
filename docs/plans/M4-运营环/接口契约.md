# M4 运营环 · 接口契约

> 状态：已拍板（随 PRD 冻结）｜设计冻结包 3/4

## 一、工具面新增（AI 可调用，共 10 个）

### save_report（jco_save_report）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| metrics | object | ✅ | 指标对象（如 `{views, fans, comments}`）|
| note | string | ✕ | 一句话解读 |

返回：确认文案。写入 `report-latest.json`（覆盖）。

### save_comments（jco_save_comments）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| items | array | ✅ | 评论数组（≤50）：`{id, author, text, draft}` |

返回：确认文案（含条数）。写入 `comments-latest.json`（覆盖）。

**红线**：两个工具均为"写入本机数据"，无对外副作用；全集无 publish/delete/submit 类词汇（测试守着）。

## 二、数据文件

```json
// report-latest.json
{ "platform": "douyin", "at": 0, "metrics": { "views": 0, "fans": 0, "comments": 0 }, "note": "" }
// comments-latest.json
{ "platform": "douyin", "at": 0, "items": [ { "id": "", "author": "", "text": "", "draft": "" } ] }
```
