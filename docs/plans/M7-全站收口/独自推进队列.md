## 硬规矩（每轮必守）

1. 一轮 = 一个**最小完整工作单元**（宁做小做全，不贪多）。
2. **门禁 = ground truth**：`npm run gate` 全绿（含全站一致性审计）+ 两道 UI 门——这是唯一可信的"真的成了"；不靠自述。
3. **完成定义（缺一不可）**：功能真化 → 门禁全绿 → **打包装机**（electron-builder + 静默安装 + 冒烟）→ 更新《台账》与 README → 提交（=回滚检查点）。
4. **开头读、结尾写**（Ralph：下一轮看不到上一轮推理）：每轮先读《台账》+ 本文件确认状态；结尾在台账写一行"本轮做了什么/卡在哪"，并提交。
5. **先搜再动，不假设**（Ralph）：动手前先 `rg`/读现状，不假设"没实现/没做过"。
6. **单轮预算**：单轮时间盒 ≈ 1 小时、且只跑一个门禁/打包（验证串行，防回压）；超预算即停、登记、下轮续——不烧钱长跑。
7. **红线**：发布按钮人点；不爬取；未真化区域必须挂"演示版"标；不擅自改既定外观方向。
8. **停手条件**（登记并跳过，继续别的或结束本轮）：需要平台登录扫码 / 需要外观或方向拍板 / 门禁失败且当场修不好（保持可回滚）。
9. 失败不硬撑；每轮只在"失败或需要人工"时发通知，成功保持安静。
