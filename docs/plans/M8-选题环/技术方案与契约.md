# M8 选题环 · 技术方案与接口契约（对照实现冻结）

> 说明：本批因"内容动线"推进节奏，施工与文档并行完成；本文与**实际实现逐项一致**（实现即冻结），E2E 已在 gate 内。

## 一、数据契约（全部本机 localStorage · 单一事实源）

| 键 | 结构 | 写入方 | 读取方 |
|---|---|---|---|
| `jco-inspo-v1` | `[{ t, text, why, structure, myTitle, hook, who }]`（最多 10 条，新在前） | 选题页（贴入拆解成功后） | 选题页（渲染拆解卡） |
| `jco-radar-v1` | `[{ kind:'hot'|'ai'|'cmt', kindName, heat, title, why? }]`（最多 60 条） | 选题页（换一批 / 想题 / 评论挖题） | 选题页（雷达列表） |
| `jco-favs-v1` | `[title, …]`（最多 100） | 选题页（星标收藏/取消） | 选题页（收藏 tab） |
| `jco-script-v1` | `{ topic, lines:[…], xhs:bool, t }` | 创作页（每次生成成功后覆盖） | 创作页（首屏恢复） |
| `jco-pick-topic`（sessionStorage） | `string` | 选题页（点卡/拿去开写） | 创作页（消费即清） |

## 二、选题页逻辑（三条真能力）

1. **AI 出题**：「换一批」→ `kernel.task`（系统提示词：成人学历赛道、实用、不夸大、不碰"包过"）→ 今日热点 3 条 → 入 `jco-radar-v1`（kind=hot）；底部条"让 AI 定方向"→ 按用户想法出 3 条（kind=ai）；
2. **评论挖题**：切「评论挖题」tab → 读 M4 数据 `publish.data.get()` → 无数据=如实空态（引导去运营页取评论）；有数据 → 评论文本（最多 20 条）→ AI 输出 `题目|为什么` → 入雷达（kind=cmt，持久化，不再重复挖）；
3. **贴爆款拆解**：弹层贴入（≤1500 字）→ AI **一次拆全**（严格 5 行：为什么火/它的结构/我的标题/我的开头/讲给谁听）→ 存 `jco-inspo-v1` → 卡片展示（展开看拆解；「拿去开写」→ 创作页 /「开始做视频」→ 做视频页）。

**红线纪律**：不爬取、不搬运；拆解对象=用户自行粘贴的内容；AI 提示词固定写入"不夸大承诺、不碰违规说法"。

## 三、创作页收尾（同批）

- 进页消费 `jco-pick-topic` → 「正在写：《题》」变为真题；稿区无稿时显示**空态**（不再出现假样例稿）；
- 生成成功 → 覆盖 `jco-script-v1`（含是否小红书版）；**重启/回页后恢复真稿**；
- 「换主题」真模式 → 跳「选题」挑（不再演示轮换）；「自己出题」保持真生成。

## 四、E2E 用例（已进 gate：`app/tests/e2e/m8-topics.spec.mjs`）

| # | 场景 | 断言 |
|---|---|---|
| 1 | 选题页真数据渲染 | 预置 inspo/radar/favs → 拆解卡/雷达/收藏态正确 |
| 2 | 点题开写 | 点卡 → 跳创作页 + **创作页接住主题**（交接键被消费清除属设计行为） |
| 3 | 评论挖题空态 | 本机无评论数据 → "还没有评论数据——去运营页取一次" |
| 4 | 创作页 | 无题=空态；带题=真题主题+空稿；有 `jco-script-v1`=恢复真稿 |
| 5 | file:// 冒烟 | 空态/弹层/无内核提示，零 JS 错误 |

**真机实测（B 级，2026-10-16）**：贴入真实爆款文案 → AI 拆出可用版本（标题/开头/受众/结构全字段）；「换一批」→ 真出 3 条热点题（首条命中"10月18日开考"实时节点）；全程零 JS 错误。
