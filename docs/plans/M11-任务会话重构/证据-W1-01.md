覆盖：

### C-01 首页发送创建新会话

- 默认落到 `#/home`；
- 在首页输入“你好”并发送；
- 进入 `#/chat/<id>`；
- 总管页出现用户消息“你好”；
- `window.jco.tasks.sessions()` 前后数量一致，**没有创建 Task**；
- `window.jco.publish.session.status()` 前后都不是 active，**没有启动 BrowserSession**；
- `jco-chats-v1` 中出现真实的用户消息。

### C-02 第二个会话独立

- 第一个会话发送“第一个会话”；
- 点壳侧栏“新会话”；
- 第二个会话发送“第二个会话”；
- 两条用户消息同时存在；
- 空会话数量 ≤ 1；
- 第一个会话内容未被覆盖。

### 壳内 task 路由

- 设置 `#/task/demo-task`；
- iframe 落到 `J.Co总管.html?task=demo-task`；
- 保留现有任务视图回看能力。

## 2. 实现

- `J.Co应用壳.html` 增加 `#/home`、`#/chat/:id`、`#/task/:id`、`#/page/:file` 路由；
- 首页发送通过 `parent.__jcoStartChat()` 进入 `chat/new`，由总管页创建会话并发送；
- `J.Co总管.html` 新增 `?new=1&seed=...` 消费逻辑，并回传会话 id 给壳，地址栏稳定到 `#/chat/<id>`；
- 首页提交删除 `tasks.dispatch`，不再把聊天误当派活；
- 首页移除“暑期招生”等 4 处行业写死文案。
