# W2-02 证据：素材页迁移

- 日期：2026-10-18
- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**verified**

## 1. 目标 E2E

```powershell
cd app
npx playwright test tests/e2e/m11-materials-store.spec.mjs
```

结果：`1 passed`。

覆盖：

- 旧 `jco-materials-v1` 首次进入时迁移到统一 `materials.json`；
- 真实走“导入素材”链路（测试模式用固定文件替代系统选择框），导入项写入统一数据层；
- 导入后旧 localStorage 不再新增双写，仍保留原 1 条迁移来源数据；
- 刷新后由统一数据层恢复 2 条素材；
- 做视频页“手头素材”读取同一份索引，显示 `素材 2 件`；
- BrandProfile（健身 / 上班族 / 直接）进入画面方案提示词。

## 2. 实现

- 主进程新增 `materials.json` 数据层：读取、字段规范化、原子写、旧数据迁移；
- `materials:get/save/migrate` IPC 与 preload 受控 API；
- 新增 `brand:get` IPC 与 preload 受控 API，供素材页读取 BrandProfile；
- 素材页启动时先渲染旧数据，再异步 hydrate 统一数据层；
- 桌面应用不再新增旧 `jco-materials-v1` 写入；旧 key 只做一次性迁移和浏览器降级读取；
- 做视频页“手头素材”优先读取统一数据层，旧 localStorage 仅作首屏降级；
- E2E 数据护栏扩展到 `materials.json`；
- E2E 测试模式支持 `JCO_TEST_PICK_FILES` 固定文件，覆盖真实导入链路而不弹系统对话框。

## 4. 已知边界（不虚报）

- 素材只存索引与路径，二进制仍在本机原位置；文件被移动或删除时预览会失败，页面不会伪造内容；
- 统一数据层为空时才迁移旧 localStorage；若已有新数据，旧数据不自动合并（与 W2-01 同一迁移策略）；
- 素材页和做视频页仍是旧 iframe 结构，组件级原生化留到后续；
- 画面方案只接 BrandProfile 提示词，未新增素材级 Artifact 或任务卡。
