
覆盖：

- 设计系统页展示总管同款用户消息、AI 消息、消息动作和 Markdown 渲染；
- 展示任务卡草稿、字段、错误提示、确认 / 修改 / 取消操作；
- 展示任务状态：待确认、执行中、等你确认、已完成、失败、已取消；
- 展示员工状态：在忙、在等你、空闲、已排期；
- 展示默认、已填、不可用和错误表单状态；
- 共享 CSS 存在消息 / 任务状态 / 员工状态规则，产品页不再重复定义；
- 任务状态行在窄卡片内自动换行，不溢出；
- 设计系统页无 JS 错误。

## 2. 实现

- 将总管页的消息、消息动作和 Markdown 消息样式迁入 `assets/jco-ui.css`；
- 将应用壳的任务详情状态与任务详情子组件样式迁入共享层，壳只保留视图定位；
- 将自动任务、技能库、管家团队三页重复的员工状态徽标样式收编到共享层；
- 设计系统页新增消息、任务卡、任务状态、员工状态和表单状态样例；
- 设计系统页复用 `assets/message.js` 渲染 AI 消息，不另写一套 Markdown 渲染；
- `scripts/audit-frontend.mjs` 新增设计系统与产品组件同源检查；
- 表单禁用态使用共享 token，避免“看起来可编辑但实际不可用”。
