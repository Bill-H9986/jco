# W3-04 证据：BrowserSession 生命周期 + 平台适配

- 日期：2026-10-18
- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**工具层 verified；平台真实登录/发布仍需按平台实测**

## 1. 真浏览器冒烟

```powershell
cd app
$env:JCO_BROWSER_SMOKE='1'; npx vitest run tests/unit/publish-session-browser.test.mjs
```

结果：`1 passed`。

实测链路：

- 启动真实 Edge 持久化上下文（测试模式 headless，生产仍有头）；
- `PublishSessionManager` 进入 `active / ready / douyin`；
- 读取本机会话 endpoint/token；
- 打开白名单域名 `https://creator.douyin.com/robots.txt`；
- `snapshot` 返回真实页面快照；
- `stop` 后会话在等待窗口内退出，`active=false`。

## 2. 生命周期与适配

- `PublishSessionManager` 增加 `headless` 配置，测试可无头，生产仍默认有头；
- 平台注册表新增契约测试：五个平台都有域名白名单和 https 发布页，发布页域名必须落在自己的白名单内；
- 未知平台不再静默回退抖音，session-server 直接拒绝；
- 既有 `publish-adapters.test.mjs` 继续校验抖音适配包恰好 5 个方法；
- 会话状态继续由 session 文件的 `pid + platform` 双重校验，避免切平台误判 ready。

## 4. 已知边界（不虚报）

- 平台适配包目前只有抖音；视频号/小红书/B站/快手有登录会话白名单，但没有各自发布适配包；
- 不扫码、不登录、不点击发布；真实登录仍需用户亲手完成；
- 其他平台的发布页/选择器改版仍需逐个平台实测；
- 生产会话默认有头，测试使用无头 Edge；真实桌面发布窗口行为仍需安装版最终验收。
