# 证据：侧栏收起文字/横向滚动条与账号统一（0.6.0-beta.39）

> 日期：2026-10-21
> 范围：应用壳侧栏收起态“新会话”按钮、全站用户账号显示。

## 一、侧栏收起 bug

现象：侧栏收起后，“新会话”蓝色方块中仍透出“会话”文字。

先红测试：M7 读取按钮内所有非图标文本节点的可见宽度。

```text
Expected: 0
Received: 13
```

根因：

- 早期规则 `html:not(.side-pinned) .convo.new-btn { font-size: 0; }` 被后续全局控件的
  `body .convo.new-btn { font-size: var(--jco-control-font) !important; }` 覆盖；
- 图标本身正常，但按钮里的原始文本节点随 14px 字号重新显示。

修复：收起态使用更高优先级并显式设置 `font-size: 0 !important`、`gap: 0 !important`、
`padding: 0 !important`，图标保持 18px。M7 重跑通过。

### 第二轮：底部横向滚动条

用户截图显示收起态底部出现“左箭头 + 灰色滑块 + 右箭头”。

先红测试：

```text
overflowX: auto（应为 hidden）
scrollWidth: 70px；clientWidth: 44px
```

根因：

- 收起态仍保留展开态导航项的内边距和图标间距；
- 分组标题与会话列表只是高度压成 0，仍以展开态宽度参与布局。

修复：

- `.side-scroll` 明确设置 `overflow-x: hidden`；
- 收起态分组标题和会话列表 `display: none`；
- 导航项宽度 100%、居中、去掉 padding/gap；
- M7 断言横向滚动必须关闭，并且内容不能再宽于容器。
