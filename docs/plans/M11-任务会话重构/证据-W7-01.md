- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**verified（四项界面/数据改动完成，完整门禁通过）**

## 1. 实现范围

- 侧栏：
  - `jco-shell.js` 将标识、搜索、新会话、首页/总管放入固定区；
  - 工作台、工具、任务、对话放入独立 `.side-scroll`；
  - 实测固定区在下方列表滚动 320px 后坐标不变；
  - 底部账号/通知区保持固定可见。
- 内容页头部：
  - 统一页面令牌 `--jco-page-top: 36px`、`--jco-page-x: 32px`；
  - 做视频、选题等 11 个内容页共用同一 `.wrap` 内边距；
  - E2E 实测“做视频”和“选题”左上元素均为 `{ x: 32, y: 36 }`。
- 内置知识库：
  - 设置页品牌档案升级为“J.Co 内置知识库”；
  - 保留品牌知识，新增资料条目、标签、启停、编辑、删除；
  - 支持导入 `.txt / .md / .csv / .json`，单文件 <= 200 KB；
  - 数据只存本机 `brand-profile.json`，最多 50 条；
  - 导入和存储前对 `Bearer / sk- / token / password / secret` 等凭据形态脱敏；
  - 聊天、任务、选题、素材、文案、做视频提示词均读取同一知识库；
  - 知识内容明确标注为资料，不当作指令执行。
- 关于：
  - 新增真实 `app.getVersion()` IPC；
  - 设置页“关于”动态显示当前版本，不在页面写死。
- 测试工程：
  - 页面增加 `data-jco-page` 就绪标记，避免记录到上一页状态；
  - 视觉截图等待页面加载、透明度结束且连续两帧一致；
  - 每轮 E2E 开始前清空 `--jco-test` 临时数据，避免中断运行留下的脏状态影响下一轮。

- 当前知识库是“本地资料直注入”，不是向量检索；条目规模适合几十条运营知识，不适合数万文档。
