# W3-03 证据：账号中心登录登记迁移

- 日期：2026-10-18
- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**verified**

## 1. 目标 E2E

```powershell
cd app
npx playwright test tests/e2e/m11-accounts-store.spec.mjs
```

结果：`1 passed`。

覆盖：

- 旧 `jco-login-v1` 首次进入时迁入统一 `accounts.json`；
- 账号中心新登记写入统一层，旧 key 不再双写；
- 刷新后账号状态保留；
- 发布页读取同一份账号登记：抖音/视频号已登记，B站未登录。

## 2. 实现

- 主进程新增 `accounts.json`：平台登录登记、字段规范化、原子写；
- `accounts:get/save/migrate` IPC 与 preload 受控 API；
- 账号中心启动先读旧登记渲染，再异步 hydrate；统一层为空时迁移旧 key；
- 账号中心登记、重登、刷新都走统一层；
- 发布页登录状态改为读 `accounts.json`，旧 key 只作迁移来源和浏览器降级；
- 修复发布页账号状态异步 hydrate 后平台不会自动选中的问题；
- 账号中心与发布页的登录状态现在由同一事实源驱动；
- 同时把消息视觉基准的字体/消息渲染等待改成确定性等待，消除本次门禁出现的偶发截图哈希抖动。

- E2E 不扫码、不打开真实平台浏览器，真实登录链路仍属于 W3-04；
