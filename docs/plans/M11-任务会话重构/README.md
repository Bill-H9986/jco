## 产品负责人需要确认的规则

1. 首页发送 = 新会话；
2. 派活 = 显式任务卡确认；
3. 纯聊天不启动浏览器；
4. 任务详情独立于聊天；
5. 自动任务与派活共用任务台账；
6. 行业由 BrandProfile 提供，不写死；
7. 发布/删除/支付永远人工确认；
8. 细节按 D0–D4 验收。

## Phase 1 施工顺序

1. Domain 类型 + TaskStateMachine + 单元测试；
2. JsonStore + 迁移 + 测试；
3. IPC + preload + 契约测试；
4. HarnessPool + PromptBuilder + 工具白名单；
5. Message 组件 + 视觉基准；
6. 首页新会话 + 聊天视图；
7. 任务卡 + 任务详情 + Approval；
8. Automation 统一台账；
9. E2E + 安装版 + 真实内核冒烟；
10. 产品负责人验收。
