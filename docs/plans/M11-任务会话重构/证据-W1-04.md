## 2. 实现

- 自动任务 `runAutoTask` 在真正执行前先创建 work task；
- 到点 `tick` 和「马上跑」`runNow` 都走同一个 `launch`；
- `runNow` 返回刚创建的 `taskId`，`tasks:run` 将它返回给页面；
- `auto-runs.json` 只保留历史读取；`saveAutoRun` 不再写文件；
- `tasks:runs:get` 从 work-task 派生最近执行结果，旧 `auto-runs` 作为兼容兜底；
- `work-tasks/` 加入 E2E 备份/恢复范围和 m6 测试清理，避免测试台账污染后续用例。

## 4. 已知边界（不虚报）

- 自动任务仍通过现有 `bridge.ask` 执行，TaskService 目前是统一台账/状态机层，尚未抽成独立 Application 类；W1-05 继续真实内核接线；
- 自动发布任务的权限/审批仍需在 W3-01 与 TaskRunner 真正接入；当前自动任务仍遵守 AUTO_DISCIPLINE 提示词，但不能把提示词当成物理审批；
- `auto-runs.json` 里已有的历史数据不会删除，只读兼容；W5 前再决定是否归档；
- 自动任务的真实失败/重试语义仍由后续任务执行单元补齐。
