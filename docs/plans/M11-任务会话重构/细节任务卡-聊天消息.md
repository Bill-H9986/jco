# 细节任务卡：聊天消息组件

- 日期：2026-10-17
- 状态：待实现
- 关联：`领域模型与交互冻结.md`、`验收用例.md` D-01 ~ D-04
- 模板：`docs/细节任务卡模板.md`

## 任务

- 组件：`MessageList` + `MessageItem` + `Composer`
- 目标用户：不懂技术、每天长时间使用聊天页的自媒体运营者
- 一句话目标：让消息像正常聊天记录一样好读、好操作、长文本不崩、深浅色一致
- 关联需求：C-03、C-04、D-01 ~ D-04

## D0 设计契约

### 参考

- 参考方向：苹果风、极简、Marvis/DSH 类聊天界面；
- 参考截图：Phase 1 开始时由产品负责人确认一张基准图，存入 `docs/plans/M11-任务会话重构/参考/`；
- 不允许用“大圆角卡片铺满 84% 宽度”的 AI 消息样式。

### Design Token

| 项 | 值 |
|---|---|
| AI 正文字号 | 14.5px |
| 用户气泡字号 | 14.5px |
| 正文行高 | 1.7 |
| 消息最大阅读宽度 | 760px |
| 用户气泡最大宽度 | 70% |
| 头像 | 32×32，圆形 |
| 消息间距 | 18–22px |
| 段落间距 | 10px |
| 列表缩进 | 16px |
| 代码块字号 | 13px，等宽字体 |
| 圆角 | 用户气泡 16px；任务卡 14px；按钮 10px |
| 颜色 | 只用 `jco-ui.css` token，不新增硬编码颜色 |

### 布局

```text
┌──────────────────────────────────────────────┐
│ 会话标题                              [⋯]    │
├──────────────────────────────────────────────┤
│                                              │
│  [J]  J.Co                                   │
│       消息正文……                             │
│       [复制] [引用] [派活]                   │
│                                              │
│                              用户消息气泡 →  │
│                                              │
│  [J]  J.Co                                   │
│       下一条消息……                           │
│                                              │
├──────────────────────────────────────────────┤
│ [输入框固定底部]                    [发送]   │
└──────────────────────────────────────────────┘
```

### 响应式

- 1440×900：消息区居中，最大阅读宽度 760px；
- 1280×800：消息区至少保留 24px 左右边距；
- 窄于 1100px：侧栏可收起，消息区不横向溢出；
- 输入框始终固定在底部，不随消息数量漂移。

### 深浅色

- 所有颜色从 token 读取；
- 深色下正文、次要文字、边框、代码块、用户气泡对比度合格；
- 不允许“外壳深色、内容区白色”。

### 明确的非目标

- 不做复杂富文本编辑器；
- 不做语音消息；
- 不做消息线程分支；
- 不做表情包/贴纸。

## D1 实现契约

### 消息状态矩阵

| 场景 | 条件 | 预期 |
|---|---|---|
| AI 普通消息 | 短文本 | 头像 + 名字 + 平坦正文 |
| AI 长文本 | 5000+ 字 | 完整显示，段落/列表/代码块可读，不截断 |
| AI 流式 | 正在输出 | 显示光标/加载态，最终替换为完整文本 |
| AI 失败 | 内核错误 | 错误卡片：人话错误 + 重试按钮 |
| 用户消息 | 普通文本 | 右对齐气泡 |
| 用户长文本 | 500+ 字 | 自动换行，不溢出 |
| 空会话 | 无消息 | 空态提示 + 建议输入 |
| 代码块 | ```...``` | 等宽字体、背景、横向滚动 |
| 列表 | `-` / `1.` | 正确缩进和项目符号 |
| 链接 | URL | 可点击，样式可识别 |
| 复制 | 点击复制 | 复制纯文本，toast 提示 |
| 引用 | 点击引用 | 输入框插入引用片段 |
| 派活 | 点击派活 | 打开任务卡，不直接执行 |
| 删除 | 点击删除 | 二次确认后删除消息 |

### 数据

必须用以下样本测试：

- 20 字短消息；
- 500 字中文长消息；
- 5000 字长消息；
- 含中英文、emoji、特殊符号；
- 含列表、代码块、链接；
- 含错误信息；
- 空数据；
- 超长单词/URL。

### 键盘

- Tab：输入框 → 发送 → 消息操作按钮；
- Enter：发送；
- Shift+Enter：换行；
- Esc：关闭弹层/取消引用；
- 焦点态必须可见。
