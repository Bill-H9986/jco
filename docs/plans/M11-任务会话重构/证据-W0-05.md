## 3. 真实内核冒烟（chat）

```powershell
node --input-type=module -e 'process.argv.push("--jco-test"); ... b.ask("请帮我打开抖音创作者中心，告诉我页面标题", null, { profile: "chat", ... })'
```

实际输出（摘要）：

```text
ok: true
text: 我这边没法直接开浏览器——按规矩，浏览器只在发布任务里由发布岗位启动，聊天这头不动它。
     要不我帮你提一张任务卡，走发布岗位去开抖音创作者中心、回来告诉你页面标题？你确认一下我就提。
toolActivities: []
closeMs: 34
```

判定：

- 模型能看到新的 chat persona（“浏览器只在发布任务里由发布岗位启动”来自 `buildChatPrompt`）；
- 没有产生任何工具活动，没有启动浏览器；
- 系统提示词不再拼进用户消息，而是通过 `system-prompt` 的 `personaPrefix` 注入。

## 4. 真实内核冒烟（publisher / editor）

```powershell
node --input-type=module -e '... b.ask("必须调用 jco_snapshot 工具看一下当前页面...", null, { profile: "publisher", ... })'
```

实际结果：

```text
ok: true
tool calls: jco_snapshot（call + result）
工具返回：没有活跃的发布会话：请先在 J.Co 里启动「发布会话」，再使用发布工具。
```

判定：publisher Harness 真实挂载了浏览器工具白名单；未启动发布会话时工具如实报错，不假装成功。

另用 `sessionId: "chat:smoke-w005"` 与 `sessionId: "task:smoke-w005"` 各跑一次，确认会话命名空间互不干扰。

editor 侧用 `sessionId: "task:smoke-editor"` 要求模型必须调用 `jco_list_assets`：

```text
ok: true
tool calls: jco_list_assets（call + result）
工具返回：成片目录为空，没有视频/音乐可处理
```

判定：editor Harness 只挂载后期工具，真实工具调用成功，且没有浏览器工具。
