- 日期：2026-10-18
- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**工具层 verified；页面 TaskService/Artifact 仍待后续**

## 1. 目标测试

```powershell
cd app
npx vitest run tests/unit/edit-tools.test.mjs tests/unit/edit-tools-runtime.test.mjs
```

结果：`2 passed / 10 tests passed`。

覆盖：

- 子进程超时：150ms 到点杀掉长进程并返回 `TIMEOUT`；
- 取消标记：标记出现后杀掉进程、返回 `CANCELLED` 并清理标记；
- 真实 ffmpeg：生成 1 秒 320×240 样片，探测时长/分辨率/音轨，再裁剪成新文件；
- 真实路径守卫：拒绝 `../` 逃逸、不存在的文件和符号链接逃逸；
- 原有 SRT、ffprobe 解析、路径字符串守卫继续通过。

## 2. 实现

- `runFfmpeg` 增加 `timeoutMs`、`cancelFile`、`cancelPollMs`；
- 超时/取消都会杀掉子进程，返回可读错误码，不把失败伪装成成功；
- `resolveInside` 使用 `realpathSync` 做真实路径守卫，挡住符号链接逃逸；
- `edit-tools.json` 写入 10 分钟默认超时与取消标记路径；
- bridge 生成的 edit-tools patch 同步注入 `timeoutMs` 和 `cancelFile`；
- `tasks:cancel` 对 `post` 会话和 `edit` 工作单元写取消标记；
- `tasks:dispatch` 启动新的后期任务前清理旧取消标记。
