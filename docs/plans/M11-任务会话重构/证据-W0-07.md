## 2. Context Pack

- 系统 / 任务优先，外部资料最后；
- 外部内容统一包在 `<external_content source="...">`；
- 单段超长带 `[已截断：原文 N 字…]` 标记；
- 整包预算不足时丢弃低优先级内容并记录 `dropped`；
- Bearer / `sk-*` / password / api_key 进入上下文前替换为 `[已脱敏]`。

## 3. 运行预算与指标

文件：

- `app/src/agent/run-budget.ts`
- `app/src/agent/run-metrics.ts`
- `app/kernel/bridge.mjs`

预算覆盖：

- 模型调用次数；
- 工具调用次数；
- token 总量；
- 墙钟时间；
- 重试次数；
- 可选输入/输出单价（未配置时 `costUsd: null`）。

`bridge.ask()` 现在返回 `metrics`：

```json
{
  "wallMs": 815,
  "modelCalls": 1,
  "toolCalls": 0,
  "toolErrors": 0,
  "tokens": { "input": 417, "output": 0, "total": 417 },
  "costUsd": null
}
```

真实预算拦截：`options.budget = { maxTokens: 1 }` 时，K-07 返回
`code: "BUDGET_EXCEEDED"`，错误为“运行预算超限：tokens 417 > 1”。

边界：DSH 当前没有轮次中取消协议，预算超限在本回合结束后强制回收该 profile；
已发生的 token 不会退回。这是**事后硬停**，不是“零消耗拦截”。

## 7. 已知边界（不虚报）

- 真实浏览器、真实 ffmpeg、安装、升级/回滚 4 条评测仍是 manual，需要对应环境；
- 未配置模型单价时 `costUsd` 为 `null`，只记录真实 token，不假装有成本数字；

- OWASP 安全门是自动可验控制项，不替代 W5-04 的人工安全评审；
- 255 条存量欠账仍在，W5 前必须清零。
