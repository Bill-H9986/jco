# W1-01A 证据：全项目行业文案通用化

- 日期：2026-10-18
- 环境：Windows · `work/jco-beta` · `beta/0.6.0`
- 结论：**verified**

## 1. 纠正的问题

上一轮只把首页的“招生”文案改成通用短视频，范围太窄。产品负责人明确要求：

> 整个项目、整个软件是通用型的；具体往哪个精细化行业发展由客户决定。

因此这次不是“改首页”，而是对 `设计原型/` 全部 HTML 做行业词清理：

- 教育行业词：`成人/学历/高考/自考/招生/学员/院校/升本/教育/培训/课程/报名`；
- 页面提示词、示例标题、评论示例、任务示例、选题/素材/创作/视频/发布/运营/总管/团队/技能库等页面。

## 3. 文案策略

- 默认示例使用“示例项目 / 内容 / 用户 / 两种方案 / 这件事”等中性词；
- 客户以后在 BrandProfile 里配置行业、受众、平台、语气、禁用表达；
- 页面不再假设教育机构、课程销售或招生场景；
- 测试数据里保留的行业词只用于验证“任意用户输入都能处理”，不属于产品默认文案。
