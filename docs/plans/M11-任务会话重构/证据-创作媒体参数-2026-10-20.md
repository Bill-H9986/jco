# 证据：创作媒体参数与素材选择修复（2026-10-20）

## 范围

- 做图：比例、清晰度、张数、空图片占位。
- 做视频：分镜解析、单段秒数、720P、模型、失败汇报、审批门。
- 素材：3:4 卡片、从创作页进入选择模式、选中回传。
- 创作页其他：真实换画面、去掉演示兜底和假标题/假配音进度。

## 根因

1. `kernel:draw` 只发送 `model / prompt / n=1`，比例和分辨率没有进接口。
2. Agnes 图片接口的分辨率参数是 `size: 1K/2K/4K`，比例参数是 `aspect_ratio`；只发像素尺寸会被平台按默认尺寸或方形处理。
3. `parseShots` 要求至少 3 段，5 秒视频只需 1 段，合法结果被删掉，导致视频模型没有启动。
4. 视频出片固定 `seconds: 5`，没有使用草稿总时长，也没有把 `size/model` 传给接口。
5. 素材页只有预览，没有选择态和回传通道；卡片缩略图固定 88px 高，图片被横着裁。
6. 视频草稿没有出片也能点“这版可以了”，会把空壳草稿带到发布页。
