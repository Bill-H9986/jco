# M6 自动任务环 · 接口契约

> 状态：**设计冻结**（2026-10-16）｜设计冻结包 3/4

## 一、IPC 清单

| 通道 | 方向 | 载荷 | 返回 | 说明 |
|---|---|---|---|---|
| `tasks:sync` | 渲染 → 主（invoke） | `{ items: 任务数组 }` | `{ ok, count, error? }` | 写 `kernel/auto-tasks.json`（调度器数据源）；字段截断清洗（同 skills:sync 纪律） |
| `tasks:runs:get` | 渲染 → 主（invoke） | — | `{ runs: { [taskId]: RunRecord } }` | 读 `kernel/auto-runs.json`（缺失返回空对象，不报错） |

## 二、preload API（window.jco 新增项）

```js
window.jco.tasks.sync(items)   // -> Promise<{ ok, count? }>
window.jco.tasks.runs()        // -> Promise<{ runs }>
```

## 三、任务 schema（localStorage `jco-tasks-v1` · 单一事实源）

```js
{
  id: 't2',                    // 稳定 id（永不变）
  name: '晚间发布检查',         // 名称（≤60 字）
  desc: '到点提醒你确认今晚的发布',  // 要干的活（自由文本，也就是任务指令）
  when: '每天 19:20',           // 展示文案（由 schedule 生成，随 schedule 同步维护）
  icon: 'ti-bell',
  on: true,
  schedule: { kind: 'daily', time: '19:20' }
  //         或 { kind: 'weekly', weekday: 1, time: '10:00' }（weekday: ISO 周一=1..周日=7）
}
```

- 迁移：老数据仅有 `when` 字符串 → 解析（`每天 HH:mm` / `每周一 HH:mm`）成 schedule；失败回退 `{kind:'daily', time:'09:00'}`；
- 四档默认：daily 09:00 · morning 08:30 · evening 18:30 · weekly(周一) 10:00；
- `when` 文案格式：`每天 09:00` / `每天早上 08:30` / `每天傍晚 18:30` / `每周一 10:00`。

## 四、执行记录 `RunRecord`（`kernel/auto-runs.json`）

```json
{ "runs": {
    "t3": { "lastRunAt": 1730000000000, "dueAt": 1729994400000, "ok": true,
            "summary": "8 条评论稿等你过目" }
} }
```

- `ok:false` 时 `summary` 为失败原因；`dueAt` = 本次对应的计划时刻（补跑时即错过的那个时刻）；
- 文件损坏/缺失 → 调度器视为无记录（任务有一次重跑机会，可接受）；页面显示"上次执行"读它。

## 五、活动事件扩展（kernel:activity）

自动任务执行产生的活动事件在既有形状上追加（其余字段不变）：

```js
{ kind:'tool', phase:'call', session:'jco-chat-auto-t3', tool:'jco_open_page',
  auto: true, taskName: '评论自动跟进', t: 1730000000000 }
```

- 渲染层（团队页）：`auto === true` 时汇报区显示 `自动任务「<taskName>」正在忙：<动作>`；`turn/end` 恢复；
- `session` 前缀 `jco-chat-auto-`（调度器专用会话，不与用户会话混）。

## 六、调度器数据流（只读契约）

```
页面（编辑）→ tasks:sync → kernel/auto-tasks.json ──读──> 调度器（每分钟）
调度器（写）→ kernel/auto-runs.json ──读──> tasks:runs:get → 页面显示"上次执行"
```

纪律：`auto-tasks.json` 由页面单向同步（调度器只读，绝不回写）；`auto-runs.json` 由调度器单向写（页面只读）。
