# M6 自动任务环 · E2E 验收用例清单

> 状态：**设计冻结**（2026-10-16）｜设计冻结包 4/4（先写"会失败"的，施工以变绿为目标）

## A 级 · 全自动（进 gate）

| # | 场景 | 断言 |
|---|---|---|
| A1 | 时间判定（单测） | 到点（now=09:00:01，last=昨天）→ 跑；未到点 → 不跑；已跑过（last=今天 09:00）→ 不跑；补跑（now=10:00）→ 跑且 dueAt=今天 09:00；超窗（晚 25 小时）→ 不跑；周任务跨周正确；00:00 边界正确 |
| A2 | 任务迁移（单测） | 老 `when:'每天 19:20'` → `{daily,19:20}`；`'每周一 10:00'` → `{weekly,1,10:00}`；乱格式 → 回退 daily 09:00；缺字段不抛错 |
| A3 | 自动任务页（E2E） | 新建任务（每天傍晚）→ localStorage 任务含 `schedule:{kind:'daily',time:'18:30'}`，when 显示"每天傍晚 18:30"；老数据进页自动迁移 |
| A4 | 同步落盘（E2E） | 进页后 `kernel/auto-tasks.json` 存在、结构合法、与页面一致 |
| A5 | 执行记录显示（E2E） | 预置 auto-runs.json → 任务卡出现"上次执行 18:30 ✓"；失败记录显示 ✗ |
| A6 | 团队页自动任务汇报（E2E） | mock `kernel:activity`（auto:true, taskName）→ 汇报区"自动任务「X」正在忙：…"；turn/end 恢复；员工卡不亮 |
| A7 | 演示模式不坏 | 浏览器直开自动任务页：无 JS 报错、静态演示保留 |

## B 级 · 半自动（真机脚本）

| # | 场景 | 断言 |
|---|---|---|
| B1 | 调度器真跑一轮（官方路由） | 造任务（计划时刻=1 分钟前、未跑过）→ 应用内等待 → 任务自动执行：新会话出现 AI 干活记录、`auto-runs.json` 写入 ok 记录、团队页汇报区亮过"自动任务" |
| B2 | 补跑与去重 | 同一任务再等一轮 tick → 不再跑（lastRunAt 去重）；改 lastRunAt 为前天 → 若在窗口内则补跑一次 |
| B3 | 发布红线 | 任务文本含"帮我发到抖音" → 执行后平台侧无发布动作（AI 停在发布前；真机由 C 级确认，B 级验证 prompt 含纪律尾注） |

## C 级 · 人工验收（真机，产品负责人）

| # | 场景 | 通过标准 |
|---|---|---|
| C1 | 到点自动跑 | 建任务"马上到点"（如 18:30）→ 到点自己开跑（无需点击）→ 通知弹出 + 任务卡"上次执行 ✓" |
| C2 | 补跑 | 错过时间后启动应用 → 自动补跑最近一次（只一次） |
| C3 | 红线 | 涉及发布/回复的任务，平台侧无动作，一切停在"等你" |
| C4 | 不重复 | 同一天不重复跑；任务暂停后不再跑 |
