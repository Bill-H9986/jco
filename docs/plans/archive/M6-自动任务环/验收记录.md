## 三、已知取舍（v1，如实记录）

1. **应用关着 = 不执行**（桌面应用常态；设置页"开机启动/托盘常驻"可让应用保持常驻）；
2. 自动任务的**执行对话**留在 `jco-chat-auto-*` 会话（不进聊天列表）；任务卡显示执行摘要 + 系统通知，"任务详情页"进 backlog；
3. 执行超过 bridge 3 分钟回合保护的：记"没跑完"，用户可手动「马上跑」（不自动重试）；
4. 升级/装机首启**不补跑**（createdAt 盖章），从下一个计划时刻开始——用户可「马上跑」立刻体验。

## 四、待产品负责人侧最终验收（C 级）

1. 打开「自动任务」页：看默认任务（今日战报 09:00 等）与"上次执行"；
2. 随便建一个任务（选"每天傍晚"）→ 关掉页面忙别的 → **到点它自己跑**（通知弹出、任务卡出现"上次执行 ✓"）；
3. 想立刻看效果：点任务卡「马上跑」；
4. 红线抽查：任务内容让 AI 去发布 → 它会准备好后**停住等你**（平台侧无动作）。
