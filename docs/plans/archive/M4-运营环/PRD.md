# M4 运营环 · 产品需求（PRD）

> 状态：**已拍板**（2026-10-16 产品负责人"都干！"）｜设计冻结包 1/4

## 拍板记录（2026-10-16）

1. 三块都做，顺序：**A 战报 → B 回评论 → C 线索**；
2. 评论回复："你点头之后"由 **AI 代发**（点头即授权）；作品"发布"按钮红线不变（永远用户亲手点）；
3. 战报先接**抖音**，其余平台随首次登录逐个开。

## 一、三块需求

### A. 今日战报（看数据）

- 用户在运营页点「马上跑」→ 发布会话启动 → AI 打开平台创作者中心数据页 → 读近 7 天数据（播放/新增粉丝/评论）→ **用 jco_save_report 存入本机** → 运营页"今日战报"显示真实数据 + AI 一句话解读。
- 红线：**只读**（绝不在数据页做任何操作）；读取频率默认每天 1 次（防风控）。

### B. 评论要你过目（回评论）

- 用户在运营页点「取评论」→ AI 打开评论管理页 → 读取待回评论 → 挑选重要几条 → 拟好回复稿 → **用 jco_save_comments 存入本机** → 运营页展示（评论 + 拟稿）。
- 用户点「就这么发」→ 跳总管 → AI 执行回复 → 运营页记录已回。
- 红线：**点头前绝不发送**；回复内容永不承诺效果（教育行业话术自律）。

### C. 私域线索（引流）

- v1 只做**识别与登记**：从已取回的评论中提取意向线索（如"想报名/多少钱/怎么学"）→ 运营页"私域线索"列表。
- 红线：**不自动私信、不主动私聊**。

## 二、明确不做

- 自动私信/主动私聊；爬取他人账号；一次上全平台；改动运营页既定视觉与交互。

## 三、验收标准（能演示）

1. 点「马上跑」→ 运营页战报变为**今天的真实数据**；
2. 点「取评论」→ 出现**真评论 + AI 拟稿**；点「就这么发」→ 平台侧**真实回复成功**；
3. 线索区出现从评论识别出的意向线索。
