# M4 运营环 · E2E 验收用例清单

> 状态：已拍板（随 PRD 冻结）｜设计冻结包 4/4（先写"会失败"的，施工以变绿为目标）

## A 级 · 全自动（进 gate）

| # | 场景 | 断言 |
|---|---|---|
| A1 | 工具全集 = 10（8 浏览器操作 + 2 数据提交） | 无危险词；实现与浏览器操作白名单 1:1 |
| A2 | 会话服务 dispatch 支持 save_report / save_comments | 静态：源码含两工具名且校验逻辑含 DATA_TOOLS |
| A3 | 运营页存在「马上跑」「取评论」入口 | 按钮存在（下轮 UI 施工后启用断言） |
| A4 | 演示模式不坏 | 浏览器直开运营页无报错 |

## B 级 · 半自动（本机可跑）

| # | 场景 | 断言 |
|---|---|---|
| B1 | 会话服务写数据文件 | 调用 save_report 后 `report-latest.json` 存在且结构合法 |
| B2 | IPC 读取 | `publish:data:get` 返回已写入数据 |
| B3 | 未启动会话时 | 工具返回"没有活跃的发布会话"引导语 |

## C 级 · 人工验收（真机，产品负责人）

| # | 场景 | 通过标准 |
|---|---|---|
| C1 | 战报 | 点「马上跑」→ 运营页显示**今天的真实数据** + 一句解读 |
| C2 | 取评论 | 出现真评论 + AI 拟稿（≥1 条） |
| C3 | 点头才发 | 未点头时平台侧**无任何回复**；点「就这么发」后真实回复成功且内容与拟稿一致 |
| C4 | 线索 | 线索区出现 ≥1 条从评论识别的意向线索 |
