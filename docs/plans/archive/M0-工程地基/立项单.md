# 里程碑立项单：M0 工程地基

（按《J.Co 软件开发工作流标准》附录 A 模板填写）

- **提出日期**：2026-10-16
- **一句话目标**：把《开发工作流标准》里的工具链与门禁全部落地，形成"一条命令全绿 + 一键安装"。
- **为什么做（用户价值）**：这是"不再返工、不再跑偏"的物理保障——后续每个里程碑都在它上面跑，问题在到人眼前之前就被机器拦住。
- **做什么（范围）**：
  1. 装齐工具链：TypeScript / Biome / Vitest / Playwright Test / electron-builder / commit-and-tag-version
  2. 建 `npm run gate`（一条命令跑全部门禁）与 `.githooks` 提交前快检
  3. 把关键动线正式化为 Playwright 自动化冒烟套件（首批：全站导航巡检）
  4. 打包骨架：electron-builder 配置就位，产出第一版可安装包
- **明确不做（划界）**：
  - 不动任何前端页面（设计原型\ 保持原样）
  - 不改内核桥（bridge.mjs）与主进程既有逻辑（打包路径适配除外）
  - 不把存量代码迁移到 TypeScript（只约定新代码）
  - 不涉及 M1 发布插件的任何内容
- **验收标准（能演示 / 能测的句子）**：
  - `npm run gate` 一条命令全绿（类型检查 + 代码规范 + 单元测试 + E2E 冒烟）
  - 双击安装包能完成安装、打开 J.Co 主界面
- **依赖与风险**：
  - npm 网络下载（多包，几分钟）
  - Electron 44.7.0 为指纹钉死版本，不得升级
  - Playwright 只用于 Electron 自动化，跳过浏览器下载
