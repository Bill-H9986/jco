# 里程碑立项单：M8 选题环（内容动线的源头，排期第 1 页）

（按《工作流标准》附录 A 模板填写 · 草案）

- **提出日期**：2026-10-16
- **一句话目标**：把「选题」页从演示变真——AI 帮你出选题、从你的评论里挖选题、你贴爆款它拆结构；选中的题一键送到「创作」页开写。
- **为什么做（用户价值）**：内容动线的源头。现状：**创作页的写稿引擎已是真的**（重新生成/小红书版/按我说的改都真调 AI），但"主题"还是演示数据、创作首屏还是假样例稿——**根就在选题页没真**。做完它，选题→创作→做视频整条动线就活了。
- **做什么（范围草案 · 三条真能力，全部合规）**：
  - **A. AI 出选题**：按你的赛道（成人学历）真生成选题建议（政策动向 / 常见疑问 / 节点热点），带"为什么值得做"一句话；刷一批换一批；
  - **B. 评论里挖选题**：接 M4 运营数据——把"评论里问得最多的问题"聚成选题（你的观众亲口点的题）；
  - **C. 贴爆款拆结构**：**你手动贴**一条爆款链接或文案，AI 帮你拆它的钩子/结构/节奏，套到你的题上（**不爬别人账号**——M4 红线不变）；
  - **D. 交接**：选中题 → 「创作」页"正在写：《…》"变成真题 → 「重新生成一版」直接产出。
- **明确不做（划界）**：
  - 不爬取/抓取任何他人账号数据（红线）；不做"全网爆款自动搬运"；
  - 不改选题页定稿视觉（只把演示数据换真 + 接真交互）；
  - 自动排期/日历不在本轮（放自动任务环后续）。
- **验收标准（能演示 / 能测）**：
  1. 选题页打开：**不再显示假爆款列表**；AI 出一批真选题（点击可换一批）；
  2. 评论数据存在时：出现"观众问最多"的选题区块（来源可点回评论）；
  3. 贴一条爆款文案 → AI 拆出结构卡片（钩子/节奏/落点）；
  4. 点选题「就做这个」→ 创作页"正在写"变成该题 → 点「重新生成一版」出真稿；
  5. 两道 UI 门 + 全量门禁绿；打包装机。
- **依赖与风险**：
  - 依赖：内核 task（已用于创作页，成熟）；M4 评论数据（有则展示、无则如实提示）；选题页与其交接机制（已有 sessionStorage 流转雏形）。
  - 风险：AI 生成选题的"质量波动"（系统提示词写死约束：实用、可拍、不夸大）；生成时长（复用创作页 100 秒超时与忙碌态模式）。
