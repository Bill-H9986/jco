# M1 发布工作流 · 接口契约

（通用契约：平台无关；各平台差异见第二节"适配层契约"）

> 状态：**已冻结**（2026-10-16 产品负责人拍板通过；改动走变更单）｜制定日期：2026-10-16
> 设计冻结包 · 第 3/4 件

## 一、IPC 契约（渲染层 ↔ 主进程）

| 通道 | 方向 | 载荷 | 返回 |
|---|---|---|---|
| `publish:start` | invoke | `{ platform: 'douyin' \| …, videoPath, title, topics: string[] }` | `{ ok: true, taskId }` 或 `{ ok: false, error }` |
| `publish:stop` | invoke | `{ taskId }` | `{ ok }` |
| `publish:status` | invoke | `{}` | `{ state, detail?, taskId?, platform? }` |
| `publish:event` | main → renderer | `{ platform, state, detail?, error? }` | — |

**state 枚举**：

`idle | launching | opening | awaiting_login | uploading | filling | ready | stopped | error`

对应界面文案（状态条）：

| state | 显示 |
|---|---|
| launching | 正在启动发布助手… |
| opening | 正在打开抖音… |
| awaiting_login | 请扫码登录抖音（登录后自动继续） |
| uploading | 正在上传视频 {detail} |
| filling | 正在填写标题与话题… |
| ready | 已填好，等你确认（去浏览器过目后自己点发布） |
| stopped | 已停止 |
| error | {friendly 错误文案} |

## 二、适配层契约（每个平台适配包必须实现）

适配包 = `app/publish/platforms/<平台>/`，其中 `adapter.mjs` 必须导出以下接口（引擎只认这些；**这就是"各平台差别"的全部收口处**）：

| 方法 | 签名 | 职责 |
|---|---|---|
| `open` | `async (page) => void` | 打开该平台发布页 |
| `detectLogin` | `async (page) => 'logged_in' \| 'need_login'` | 登录检测 |
| `uploadVideo` | `async (page, filePath, onProgress) => void` | 上传视频并等待完成 |
| `fillMeta` | `async (page, { title, topics }) => void` | 填写标题与话题 |
| `waitForReady` | `async (page) => void` | 判定"已到达发布前" |

另附 `rules.json`（平台规则卡，供文案生成与界面提示读取）：

```json
{ "titleMax": 55, "topicsMax": 5, "video": { "maxGB": 4, "formats": ["mp4", "mov"] } }
```

**禁止项（红线）**：适配包不得实现"点击发布"的任何能力；引擎不提供调用它的入口。

## 三、子进程协议（主进程 ↔ 引擎子进程，stdio 行 JSON）

- **启动**：参数经 argv/env 传入（videoPath / title / topics / profileDir / 调试开关），不走 stdin。
- **主进程 → 子进程**（stdin 每行一个 JSON）：`{"cmd":"stop"}`
- **子进程 → 主进程**（stdout 每行一个 JSON）：

```json
{"type":"state","state":"opening"}
{"type":"state","state":"awaiting_login"}
{"type":"state","state":"uploading","detail":"42%"}
{"type":"state","state":"ready"}
{"type":"error","code":"PAGE_CHANGED","message":"找不到标题输入框"}
{"type":"log","message":"diagnostic only"}
```

- stderr：仅诊断日志，不进状态机。
- 子进程退出码：0 = 正常结束；非 0 = 异常（配合 error 事件）。

## 四、数据结构（本地数据层扩展）

```json
{
  "id": "pub_xxx",
  "platform": "douyin",
  "videoPath": "C:\\...\\素材\\video-xxx.mp4",
  "title": "……",
  "topics": ["#学历提升", "#成考"],
  "state": "ready",
  "createdAt": 0,
  "updatedAt": 0,
  "note": "已交接，等待用户手动发布"
}
```

兼容性：已有发布记录数据无 `platform` 字段时视为本地草稿，读取不报错。

## 五、错误码表

| 码 | 含义 | 用户文案（friendly） |
|---|---|---|
| `BROWSER_MISSING` | 未找到 Edge | 没找到 Microsoft Edge 浏览器，请先安装 |
| `LOGIN_TIMEOUT` | 登录等待超时 | 等扫码等太久了，先收工；要继续再点一次 |
| `PAGE_CHANGED` | 页面结构变化 | 抖音页面改版了，需要我更新一下适配 |
| `UPLOAD_FAILED` | 上传失败 | 视频上传没成功，可以再试一次 |
| `TIMEOUT` | 其它步骤超时 | 这一步等太久了，已停止；可重试 |
| `BUSY` | 已有任务进行中 | 上一个发布还没结束，先等它完成 |
| `PLATFORM_UNSUPPORTED` | 未知平台 | 这个平台还没有做适配 |
| `INTERNAL` | 未分类 | （原始信息 + "请把这段话发给产品负责人"） |

## 六、行为红线（契约级，测试须验证）

1. 适配接口不提供"点击发布按钮"的能力函数（代码级无此方法）——E2E 断言清单含此项
2. 任何失败不得伪装为成功；状态与真实浏览器状态一致
3. 登录态 profile 目录只在本机（路径见技术方案 3.3）
4. 停止命令必须最终关闭浏览器进程（无孤儿进程）
