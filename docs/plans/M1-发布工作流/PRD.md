## 一、背景

- 五环工作流（做视频 → 发布 → 看数据 → 回评论 → 引流）中，**发布是唯一尚未真化的环节**——当前发布页在应用内标注"预演完成"。
- 产品叙事"AI 在干"需要第一个真正会干活的"员工"落地。
- 产品负责人（2026-10-16）指定：**第一个平台 = 抖音**。
- 产品负责人（2026-10-16）明确架构方向：**发布工作流必须是通用的**——所有平台共用同一条工作流；各平台的细微差别与规则由"适配层"消化（见技术方案·引擎/适配层边界）。

## 二、目标（一句话）

**发布工作流通用化**：用户在发布页把内容准备好后，点一下「发布到 XX 平台」：J.Co 自动打开该平台发布页、上传成片、填好标题与话题，**停在"发布"按钮前**；用户过目、亲手点发布。v1 首个接入平台：**抖音**。

## 三、范围（v1 做什么）

1. **通用发布引擎**（写一次、所有平台共用）：发布页入口与状态区（进度可见：启动中 / 等待扫码 / 上传中 / 填写中 / 已就绪）；独立打开系统 Edge 浏览器 + 本机专属登录态（扫码一次、长期有效；只在本机、不上云）；任务管理 / 状态机 / 错误提示 / 发布记录
2. **平台适配包 · 抖音首发**：抖音的页面操作（上传 / 填写）+ 平台规则卡（标题字数、话题数量等；新建平台 = 只写这一个包）
3. **自动化三件事**：
   - 上传视频（素材库里已落盘的成片文件）
   - 填标题（发布页已生成/已选定的标题文案）
   - 填话题（# 分层话题）
4. **未登录引导**：弹出扫码提示，登录完成后自动继续，无需二次操作
5. **随时可停**：点「停止」关闭助手、复位状态
6. **记录**：本地数据层新增"发布记录"（状态：**已交接**，等待用户手动发布）

## 四、明确不做（v1 边界，防跑偏）

- ❌ 不自动点"发布"（红线：发布动作永远由用户亲手完成）
- ❌ 不做封面自动化（封面在抖音页面上由用户自选；v2 评估）
- ❌ 不做定时发布 / 多平台 / 手机端
- ❌ 不绕过平台风控与验证码（遇到则暂停并如实提示）
- ❌ 不改动创作 / 做视频 / 素材现有流程与页面习惯

## 五、用户流程（主路径）

```
发布页（标题/话题已备好）
   → 点「发到抖音」
   → 状态：正在启动发布助手（打开浏览器 → 抖音发布页）
   → （首次）状态：等你扫码登录 → 用户扫码 → 自动继续
   → 状态：正在上传视频 → 正在填写标题与话题
   → 状态：已填好，等你确认 —— 应用提示"去浏览器里过目，然后自己点发布"
   → 用户检查后亲手点"发布"
   → 应用记录：已交接（时间 / 标题 / 视频文件）
```

## 六、验收标准（能演示 / 能测）

1. 能演示：发布页点击 → 抖音发布页打开 → 视频上传完成 → 标题与话题出现在对应输入框 → **停在发布前，无任何自动发布动作**
2. 未登录场景：给出明确的扫码引导，登录后自动继续
3. 「停止」随时可用；停止后浏览器关闭、状态复位
4. 全程零"AI 自动发布"行为（代码级保证，见契约）

## 七、红线（不可越）

1. **发布动作 = 用户手动**（本插件永不点击"发布"按钮）
2. **登录态只在本机**（不上云、不搬家——沿用账号中心既定原则）
3. **出错如实报告**（不把失败伪装成成功）
4. **不改现有页面视觉与交互习惯**（新增入口与状态区走 UI Kit 零件，过两道门）

## 八、依赖与假设

- 本机有 Microsoft Edge（Windows 标配；缺失时给出明确提示）
- 抖音创作者中心发布页面向 PC 浏览器，且需要登录
- 成片已由做视频/素材流程落盘到本机素材文件夹

## 九、多平台扩展路线

- **引擎做一次，平台逐个接入**：每新增一个平台 = 写一个"适配包"（页面选择器 + 填写策略 + 规则卡），其余全部复用；界面上的入口自动多一个平台选项。
- **接入顺序**：抖音（首发，随 M2 施工）→ 其余平台按同样节奏逐个加；每个平台都必须过同一套验收（含真站人工验收 C 级）才算出。
- **平台规则的处理**（回答"规则是不是 AI 的事"）：
  - 硬规则（字数上限、话题数量、视频规格）→ 写进该平台的**规则卡**（rules.json），文案生成与界面提示自动遵守——不靠模型临场猜，可测、可更新；
  - 软规则（内容合规、风格适配）→ 由 AI 在内核生成文案时把握（用户随时可改）；
  - 这样：规则明确、责任清楚、每个平台都能独立验收。
- **待产品负责人圈定**：除抖音外首批接入哪些平台（候选：视频号 / 小红书 / B 站 / 快手 / 微博）。
