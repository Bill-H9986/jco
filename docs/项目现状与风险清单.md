```text
Electron 桌面壳
  └─ 唯一应用壳（侧栏 + iframe 内容视图，承载 15 个内容页）

            ├─ DSH 内核桥（模型对话 / 生成）
```

## 二、当前代码实际能力

### 2.1 页面

现行 HTML 共 16 个（14 个业务页 + 应用壳 + 设计系统页），另有 2 个备选稿已归档到 `docs/archive/prototypes/`。

业务主线：

- 首页：一句话发送后创建新会话并进入聊天；只有明确任务意图才进入任务卡，不默认启动浏览器。
- 总管：聊天、多会话、任务分区、任务回看、通知。
- 选题：AI 出题、评论挖题、贴爆款拆解。
- 素材：系统文件导入、素材箱、AI 画面方案。
- 文案（文件名为 `J.Co工作台-创作.html`）：口播稿 / 小红书稿、体检、提词器、按用户意见改稿。
- 创作（文件名为 `J.Co工作台-做视频.html`）：分镜、出图、分段出片、草稿箱。
- 后期：选成片 → 对 AI 说怎么改 → 创建 `edit` Task（`editor` 岗位）→ 最终审批后执行 ffmpeg → 只把新成片登记为产物。
- 发布：AI 配标题 / 话题 / 介绍 / 封面；当前另有“预演发布”流程。
- 运营：战报、评论拟稿、线索；真实数据来自本机 `publish/data`。
- 账号中心：启动 AI 专用浏览器登录平台，并记录本机登录登记。
- 设置：模型配置、主题、开机启动、托盘、通知、模式、素材目录、公司业务/产品、AI 自动记忆开关等。
- 自动任务：任务表、启停、到点执行、马上跑。
- 技能库：16 项技能，启用状态同步给内核。
- 管家团队：结构化任务台账驱动员工「在忙 / 在等你」，任务取消后回落；实时工具活动继续显示。

## 四、防跑偏纪律（后续会话必须遵守）

1. **开工顺序**：`AGENTS.md` → 本文件 → `README.md` → 工作流标准 → 当前里程碑设计包。
2. **先核对事实**：每次新会话先确认自己在主工程 `master` 还是 beta 工作区，再看 `git log -1`、`app/package.json`、安装版文件版本、`git status`；不要把两条线的版本混在一起，也不要凭上一轮摘要里的“已完成”继续做。
3. **“真”必须有证据**：说“全真 / 已完成 / 唯一管道 / 工具层无法发布”时，必须能指出具体代码和测试；否则只能写“界面已接 / 计划接”。
4. **文件版本与安装版分开写**：`HEAD`、`tag`、`release`、桌面安装版是四个不同事实。
5. **每批改动同步更新本文件**：至少更新“最后核对”、版本事实、已关闭 / 新增风险；没有更新就视为交付不完整。
6. **不把本文件当需求文档**：它记录当前事实与风险；产品需求仍走立项单 / PRD / 变更单。
